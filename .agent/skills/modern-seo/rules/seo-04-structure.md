# SEO Rule: Content Structure & Hierarchy

Google relies on semantic HTML headings to understand content structure.

## The Rule

Maintain a strict **H1 -> H2 -> H3** hierarchy. Never skip levels.

## Checklist

- [ ] **H1**: Exactly one per page. Must contain Primary Keyword.
- [ ] **H2**: Main sections. Use Secondary Keywords.
- [ ] **H3**: Detailed subsections.
- [ ] **First 100 Words**: Primary keyword must appear in the first paragraph.
- [ ] **TOC**: recommended for long articles (>2000 words).

## Featured Snippet Optimization

To target "Position Zero":

- Place a concise definition (40-60 words) immediately after an H2 question (e.g., "What is X?").
- Use bullet points (`<ul>`) or numbered lists (`<ol>`) for steps.
