# SEO Rule: Title Tag Optimization

Title tags are the #1 on-page ranking factor (after content quality).

## The Rule

Titles must be **50-60 characters**, contain the **Primary Keyword** early, and include a **Hook**.

## Template

```
[Primary Keyword]: [Hook/Value Prop] - [Brand]
```

_or_

```
[Hook/Value Prop] [Primary Keyword] - [Brand]
```

## Examples

| Status  | Title                                                 | Why                                      |
| ------- | ----------------------------------------------------- | ---------------------------------------- |
| ❌ Bad  | Home - CleverPrices                                   | No context, no keywords.                 |
| ❌ Bad  | Gaming Laptops                                        | Too generic, no brand, no hook.          |
| ✅ Good | Best Gaming Laptops Under $1000 (2025) - CleverPrices | Valid length, strong hook, clear intent. |

## Checklist

- [ ] Length: 50-60 characters (approx 580px width)
- [ ] Brand appended at end
- [ ] Unique across site (no duplicate titles)
