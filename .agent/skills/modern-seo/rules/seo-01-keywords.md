# SEO Rule: Keyword Strategy

Before touching code or content, you must identify the **Keyword Cluster**.

## The Rule

Do not optimize a page for just one keyword. Optimize for a _cluster_ that covers user intent.

## Methodology

Fill out this grid for the target page:

| Type              | Pattern                   | Purpose           | Example                     |
| ----------------- | ------------------------- | ----------------- | --------------------------- |
| **Primary**       | `[product/category]`      | The main topic    | `gaming laptops`            |
| **Transactional** | `buy [product]`           | Commercial intent | `buy gaming laptops`        |
| **Informational** | `best [product] [year]`   | Research intent   | `best gaming laptops 2024`  |
| **Long-tail**     | `[product] under [price]` | Specific needs    | `gaming laptops under 1000` |

## Validation

- [ ] Primary keyword determined?
- [ ] At least 2 secondary keywords strings identified?
