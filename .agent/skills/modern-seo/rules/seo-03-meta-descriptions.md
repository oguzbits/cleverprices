# SEO Rule: Meta Description Optimization

Descriptions do not affect ranking directly but drive **Click-Through Rate (CTR)**.

## The Rule

Descriptions must start with an **Action Verb**, contain the **UVP (Unique Value Proposition)**, and end with a **CTA**.

## Template

```
[Action Verb] the [Primary Keyword]. [UVP or specific stats]. [CTA/Hook].
```

## Examples

| Status  | Title                                                                                                                        | Why                        |
| ------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| ❌ Bad  | We have many gaming laptops on our site.                                                                                     | Passive, boring, no value. |
| ✅ Good | **Compare** the top-rated gaming laptops. We analyze specs, battery life, and benchmarks to **help you find the best deal**. | Active, specific, helpful. |

## Checklist

- [ ] Length: 150-160 characters (truncates after ~160)
- [ ] Primary keyword included (bolded in SERP)
- [ ] Action-oriented language
