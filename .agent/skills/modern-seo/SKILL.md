# Skill: SEO Audit for Modern Web Apps

Use this skill to perform a focused SEO audit on pages. The goal is to maximize search visibility and organic traffic.

## When to Use

- Before publishing a new page
- When optimizing underperforming pages
- Periodic content audits
- After major content updates
- When targeting new keywords

## Goal

Each page should rank for searches by answering user intent clearly and quickly.

---

## SEO Audit Methodology

Follow these five steps for a complete SEO audit.

### Step 1: Identify Target Keywords

Before auditing, identify the keyword cluster for the page.

#### Keyword Cluster Template

| Type              | Pattern                 | Example                   |
| ----------------- | ----------------------- | ------------------------- |
| **Primary**       | [product/category]      | gaming laptops            |
| **Transactional** | buy [product]           | buy gaming laptops        |
| **Informational** | best [product] 2024     | best gaming laptops 2024  |
| **Long-tail**     | [product] under [price] | gaming laptops under 1000 |

### Step 2: Title Tag Optimization

Title tags are the #1 on-page ranking factor.

**Checklist:**

- [ ] Length: 50-60 characters (pixel width matters more than chars)
- [ ] Primary keyword is near the beginning
- [ ] Includes a "hook" or modifier (e.g., "Best", "2024", "Review")
- [ ] Brand name at the end (e.g., " - CleverPrices")
- [ ] Unique across the site

**Template:**
`[Primary Keyword]: [Hook/Value Prop] - [Brand]`

**Example:**
`Best Gaming Laptops Under $1000 (2025 Guide) - CleverPrices`

### Step 3: Meta Description Optimization

Descriptions don't affect rank directly but drive Click-Through Rate (CTR).

**Checklist:**

- [ ] Length: 150-160 characters
- [ ] Includes primary keyword (bolded in search results)
- [ ] Starts with an active verb (e.g., "Compare", "Discover", "Find")
- [ ] Contains a unique value proposition (UVP)
- [ ] Ends with a Call to Action (if appropriate) or spec details

**Template:**
`[Action Verb] the [Primary Keyword]. [UVP or supporting details]. [Call to action or final hook].`

**Example:**
`Compare the top-rated gaming laptops under $1000. We analyze specs, battery life, and benchmarks to help you find the best deal for 2025.`

### Step 4: Content Structure & Hierarchy

Google loves structured data and logical flow.

**Checklist:**

- [ ] **H1:** Only one H1 per page. Must contain primary keyword.
- [ ] **H2s:** Break up main sections. Use secondary keywords.
- [ ] **H3s:** Detailed subsections.
- [ ] **First Paragraph:** Mention primary keyword in first 100 words.
- [ ] **Table of Contents:** Recommended for long pages.
- [ ] **Featured Snippet Bait:** concise definition or list near the top.

### Step 5: Technical & Experience Checks

- [ ] **Images:** accessible `alt` text containing keywords where relevant.
- [ ] **URL:** Short, readable slugs. `/gaming-laptops` > `/category?id=123`.
- [ ] **Internal Linking:** Link to 3-5 related pages/products.
- [ ] **Performance:** LCP (Largest Contentful Paint) under 2.5s.
- [ ] **Mobile:** Content is fully visible and tap targets are sized right.

## Quick Reference

### Character Counts

| Element          | Ideal Length                   |
| ---------------- | ------------------------------ |
| Title            | 50-60 characters               |
| Meta Description | 150-160 characters             |
| Introduction     | 40-60 words (get to the point) |

### Content Depth (Product/Category Pages)

| Depth        | Assessment                                       |
| ------------ | ------------------------------------------------ |
| Thin Content | Avoid. Add descriptions, specs, comparisons.     |
| Moderate     | Good for category listings with filters.         |
| In-Depth     | Best for "Guides" or specific high-ticket items. |

---

## Summary

When auditing a page for SEO:

1. **Identify target keywords** using the keyword cluster.
2. **Check title tag** — 50-60 chars, keyword first, hook.
3. **Check meta description** — 150-160 chars, action word, keyword.
4. **Verify keyword placement** — Title, H1, first 100 words.
5. **Audit structure** — Logical H1 -> H2 -> H3 flow.
6. **Check internal linking** — Link to related categories/products.

**Remember:** SEO is about helping the user find what they need. If it's good for the user, it's usually good for Google.
