## 🛠️ Data Quality Standards

Every CSV export from Keepa **must** include:

1. **Current Sales Rank** (Aim for < 30,000)
2. **Ratings (4.0+)** & **Review Counts (10+)**
3. **Offer Count (1+)**
4. **Price Averages** (Amazon 30/90 day, New 30/90 day)
